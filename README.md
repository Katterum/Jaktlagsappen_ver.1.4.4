# Jaktlaget 1.4.4

## Ändringar
- Kalenderns datumfält är kompakt och begränsat i bredd.
- Jaktstatistiken visar både medlemsjaktdagar och gästdagar.
- Gäster redovisas med namn, antal jaktdagar och grafisk stapel.
- Kontakter öppnas först som en ren namnlista.
- Klick på ett namn öppnar en separat detaljsida.
- Kontaktfält är låsta i visningsläget.
- Redigera-knapp låser upp telefon, e-post och kommentar.
- Spara och Avbryt finns i redigeringsläget.
- Standarddata, ren Mer-sida samt ändra/radera för jakter och observationer är bevarade.
